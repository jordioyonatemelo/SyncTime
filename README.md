# Reloj Multihorario

App PWA de relojes mundiales. Funciona 100% offline una vez instalada.

**© J. Oyonate**

## Instalar en Android

1. Abre la URL de GitHub Pages en Chrome
2. Toca "Añadir a pantalla de inicio"
3. Listo — funciona sin internet

## Activar GitHub Pages

1. Ve a **Settings** → **Pages**
2. Source: **Deploy from a branch**
3. Branch: **main** / **root**
4. Guardar — en ~1 minuto tendrás la URL
